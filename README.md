# 🥞 BlinVPN 2.0

Профессиональная система для продажи BlinVPN с интеграцией платежных систем, панелью управления и мини-приложением для Telegram

## Быстрая установка

### Автоматическая установка (Ubuntu/Debian)

```bash
curl -sSL https://raw.githubusercontent.com/Blin4ickUSE/blinvpn/main/install.sh | sudo bash
```

**После запуска скрипт...**:
1. ...установит новейшую версию проекта на сервер и установит необходимые библиотеки
2. ...запросит **данные для сертификата**: Домен для мини-приложения и панели, почта для уведомлений и порт
3. ...установит SSL сертификаты через Let's Encrypt и создаст конфигурацию Nginx
3. ...запросит **данные для .env**: Токен бота и Telegram ID админов
4. ...при необходимости запросит **данные от платежных систем**: Platega, Heleket, CryptoBot
5. ...запустит проект и настроит вебхуки (в т.ч. для Telegram Stars)

### Ручная установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/Blin4ickUSE/blinvpn.git
cd blinvpn
```

2. **Настройте .env файл:**
```bash
cp .env.example .env
nano .env
```

Заполнить все необходимые данные:
- Токены Telegram ботов
- API ключи платежных систем
- Домены для сервисов
- Настройки Remnawave

3. **Запустите установку:**
```bash
sudo bash install.sh
```

4. **Настройте DNS:**
Убедитесь, что домены указывают на IP вашего сервера:
- `A` запись для `панели` (например, panel.domain.com)
- `A` запись для `мини-приложения` (например, app.domain.com)

- Интеграция с мини-приложением

### Мини-приложение
- Пополнение баланса
- Покупка подписок
- Управление устройствами
- Реферальная программа
- Промокоды
- Договор оферты и политика конфиденциальности

### Панель управления
- Управление пользователями
- Управление ключами VPN
- Промокоды
- Рассылки
- Статистика и аналитика

## Управление сервисами

```bash
# Запуск всех сервисов
docker-compose up -d

# Остановка
docker-compose down

# Просмотр логов
docker-compose logs -f

# Перезапуск конкретного сервиса
docker-compose restart bot
```
